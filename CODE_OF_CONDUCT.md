# Code of Conduct

## The short version

Be respectful. Focus on the work. If you disagree, say so plainly
and keep it about the code, not the person.

## Expected behavior

- Use welcoming and inclusive language.
- Respect different viewpoints and experience levels.
- Accept feedback gracefully and give it the same way.
- Own your mistakes and fix them when you can.

## Unacceptable behavior

- Harassment, insults, or personal attacks.
- Discriminatory language or behavior.
- Publishing someone else's private information.
- Any conduct that would make a reasonable person stop
  participating.

## Scope

This code of conduct applies to the repository, its issue tracker,
and its pull requests. It also applies when someone represents the
project in public, for example at an event or in a discussion about
the project.

## Enforcement

The maintainer reviews reports and decides what action to take.
Actions can include a warning, removal of a comment or pull request,
or a ban from the project. Reports can be made by opening an issue
or by contacting the maintainer through GitHub.
